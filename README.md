# 资产配置测算

## 下载历史日线行情

需要 Python 3.9 或更新版本。可一次下载多个标的。沪深北六位数字代码默认使用东方财富，支持直接输入代码或显式指定交易所后缀。其他市场沿用 Yahoo Finance。

```sh
python3 prices.py 511260 600519.SS 000001.SZ AAPL 0700.HK
```

工具请求数据源可提供的历史日线，写入 `data/prices.sqlite3` 的 `daily_prices` 表。可用 `--db` 指定其他数据库。按标的和日期查询时使用 `ORDER BY date`。

| 字段 | 含义 |
| --- | --- |
| `symbol` | 含交易所后缀的标的代码，与 `date` 组成主键 |
| `date` | 交易所本地交易日 |
| `open`、`high`、`low`、`close` | 开盘、最高、最低和收盘价。东方财富采用不复权口径，Yahoo Finance 价格可能已经按拆股调整 |
| `adjusted_close` | 东方财富前复权收盘价，或 Yahoo Finance 的 Adj Close |
| `currency` | 数据源报告的报价币种或单位 |

休市或数据源没有收盘价的日期不写入数据库。其他缺失的价格字段存为 `NULL`。

重复运行会重新拉取历史，并在一个事务中替换对应标的的行情。拉取或写入失败时保留该标的已有数据，批量任务继续处理其余代码，只要有一个失败就返回非零状态。

## 一次性投入回测

```sh
python3 backtest.py --start 2020-01-01 --amount 100000 \
  --weight '511260=40%' --weight '513500=40%' --weight '518880=20%' \
  --output backtest-result.json
```

- 权重可写成 `40%` 或 `0.4`，合计须为 100%。金额使用各标的共同的报价币种。
- 从请求日期起，在所有标的首次同时有日线的日期按收盘口径建仓。按比例投入后持有，允许零碎份额，忽略手续费、滑点和税费。
- 默认使用数据库复权收盘价的比值计算收益，也可以用 `--price close` 看仅按收盘价变化计算的结果。缺失或无效的所选价格会报错。
- 可用 `--end` 指定截止日期。估值覆盖各标的共同有历史覆盖的区间，某标的当天无行情时沿用上次报价，并在明细保留报价日期。
- JSON 包含期末市值、盈亏、总收益率、最大回撤，以及每日市值、收益率、回撤、各持仓市值与实际权重。比例指标使用小数，例如 `0.12` 表示 12%。省略 `--output` 时输出到终端。

### 定期再平衡

在回测命令中加上 `--rebalance-every` 即启用。例如，`--rebalance-every 3m` 表示每隔三个月调回初始权重。

- 周期格式为正整数加单位。`d` 表示日历天，`w` 表示周，`m` 表示月，`q` 表示季度（3 个月），`y` 表示年。
- 从实际建仓日推算计划日。例如 8 月 24 日建仓，`3m` 的第一次计划日是 11 月 24 日。月份没有对应日期时取当月最后一天，下一期继续按建仓日推算。
- 计划日当天或之后首个所有标的都有报价的日期，按收盘口径调回初始权重。若多个计划日都顺延至同一个交易日，当天只调一次。初次建仓不计入调仓次数。
- `rebalances` 记录计划日、实际调仓日、调仓前后权重、各标的交易金额和单边换手率。买入金额为正，卖出金额为负。单边换手率等于买卖金额绝对值之和除以调仓时组合市值的两倍。

### 阈值再平衡

加上 `--rebalance-threshold '5%'`，当任一标的的实际权重与目标权重相差至少 5 个百分点时触发。例如目标 25%，实际权重达到 30% 或降到 20% 时触发。`0.05` 表示同一阈值。

- 仅设置阈值时，每个所有标的都有报价的估值日收盘后检查。再加 `--rebalance-every 1m` 时，只在每月计划检查日（或顺延到首个共同报价日）收盘后检查。
- 触发后，在下一次所有标的都有报价的日期按收盘口径将整个组合调回初始权重。触发日与实际调仓日分别记录。回测结束时若仍未执行，信号记录在 `pending_rebalance_signal`。

## 本地回测网站

```sh
python3 serve.py
```

打开 `http://127.0.0.1:8765`。标的列表从同一个 SQLite 行情库读取，网页可设置权重、起止日期、初始金额、计价口径、调仓周期及偏离阈值。结果包括市值与回撤走势图、期末持仓、每日估值和调仓记录，可下载完整 JSON。新增标的用行情下载命令入库后刷新页面即可。可用 `--port` 或 `--db` 指定端口或行情库。

标的列表中的「现金」可以与 ETF 一起配置，也可以设为 100%。现金固定年化收益率默认 0%，计算因子为 `(1 + 年化收益率)^(经过的日历天数 / 365)`，现金与其他标的一起参与再平衡。纯现金组合按日历日估值，默认以当天为截止日，币种为人民币。命令行使用 `--weight 'CASH=20%' --cash-annual-return '2%'`，其余标的权重合计为 80%。

### Codex Sites 版本

`python3 sites/portfolio-backtest/build.py` 从本地 SQLite 导出日期、收盘价、复权收盘价和币种，生成私有站点的静态部署文件。站点在浏览器内计算回测，使用发布时的行情快照。更新本地行情后，需重新构建和发布才会更新站点。GitHub 源码仓库不包含本地数据库、行情快照和回测报告。
